AI agents are starting to run code, move money, and act on the internet with little supervision. Most of them hold their own credentials and police themselves. An agent's competence should never be the same thing as its permission.

Karuna separates the two.

**Isolate.** Agents run in a sandbox with no network access, no keys, and no memory between tasks.

**Decide.** Every action goes through a small, deterministic policy engine and a gatekeeper that holds all the credentials. If an action breaks the rules, the agent has nothing to run it with.

**Record.** Every decision is signed and written to a tamper-evident log, so teams can see exactly what their agents tried to do and why it was allowed or blocked.

Karuna is model-agnostic. It works with Claude, GPT, Gemini, and open-weight models, and plugs into the frameworks teams already use, starting with LangChain, CrewAI, and AutoGPT.
